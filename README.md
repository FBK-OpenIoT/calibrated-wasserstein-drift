# Residual Drift Detectors under a Common False-Alarm Budget

Code accompanying the paper

> P. Grazieschi, R. Silvestri, M. Vecchio, M. Antonini, F. Antonelli.
> *Residual Drift Detectors under a Common False-Alarm Budget: A Calibrated
> Comparison with a Wasserstein Reference.*
> Submitted to Knowledge-Based Systems, 2026.

The repository will contain the stream generators, the detector
implementations, and the calibration and evaluation code used in the paper.

**Status:** the code will be released here under the BSD 3-Clause licence
upon acceptance of the manuscript.
