# Security Policy

## Supported versions

Until the first stable release, security fixes are applied to the latest
revision of the default branch only.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use
GitHub's private vulnerability reporting feature for this repository. Include
the affected version, a minimal reproduction, the expected impact, and any
known mitigation.

This is research software and must not be treated as a security, safety, or
availability control without independent validation.
